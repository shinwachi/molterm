A plugin for VisiData, the terminal spreadsheet, that draws molecules in its cells: pictures in Kitty and Ghostty, coloured Braille anywhere else. Everything above is a real session, recorded in a terminal of this size, with the drawings from a molterm server; this page only prints it back.

To use it, put molterm_visidata.py on Python's path and add import molterm_visidata to ~/.visidatarc. Then, on a column of SMILES: Alt+m adds structures, Alt+y properties, Alt+o opens a molecule, Alt+t switches between pictures and Braille, and Alt+g charts cLogP against MW, with Alt+n and Alt+b stepping from dot to dot while a card shows which molecule each is.
