The medicinal chemistry session in restty, a web terminal built on Ghostty's parser. Drawings arrive as Kitty graphics, the protocol Ghostty and Kitty use. Click the terminal and type. It runs only the commands listed in help, never a shell.

The same session in your own terminal, using Kitty, iTerm2, Sixel or Braille, whichever it supports:

curl -so molterm {{ host }}/molterm && chmod +x molterm && ./molterm demo

Or draw your own molecule with the mouse and keyboard, in a terminal with Kitty graphics. It prints the SMILES when you quit:

./molterm edit
